# Список задач

Приложение для управления задачами, использующее FastAPI и PostgreSQL. Приложение позволяет создавать, редактировать, удалять задачи и отслеживать их статус.

## Установка и запуск

1. **Клонируйте репозиторий**:

    ```bash
    git clone <URL репозитория>
    cd <папка с проектом>
    ```

2. **Установите зависимости**:

    Если у вас установлен Poetry, выполните:

    ```bash
    poetry install
    ```

3. **Настройка базы данных**:

    Создайте `.env` файл в корне проекта и добавьте строку подключения к базе данных:

    ```bash
    DATABASE_URL=postgresql://<пользователь>:<пароль>@localhost:<порт>/<имя_базы>
    ```

4. **Запуск приложения**:
    **Docker**:

    Чтобы запустить приложение с использованием Docker:

    ```bash
    docker-compose up --build
    ```

    Приложение будет доступно на порту 8000.

## API

- **POST /add_task/**: Создать задачу
  - Тело запроса:
    ```json
    {
      "title": "Заголовок задачи",
      "description": "Описание задачи",
      "due_date": "2025-05-01"
    }
    ```
- **GET /tasks/**: Получить все задачи
- **GET /task/{task_id}**: Получить задачу по ID
- **PUT /upd_task/{task_id}**: Обновить задачу по ID
- **DELETE /task/{task_id}**: Удалить задачу по ID
- **GET /tasks/search/**: Поиск задач по статусу или дате
